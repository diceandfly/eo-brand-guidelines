    Typography

    Brand Typeface

    Founders Grotesk

    EO’s typefaces are Semibold · Medium · Regular · Light · Mono Regular · Mono Light of the Founders Grotesk family.

    Founders Grotesk reinterprets the early-20th-century grotesques of Miller & Richard and Caslon, and its simple geometry, narrow apertures and tight letterspacing make it read like solid blocks at large sizes. Firm and clear, yet with humanist touches in its details, it matches EO’s attitude — serious, but pursuing creativity. The family also has a monospaced typeface that can evoke the builder’s motifs, such as engineering · spec sheets.

    Each weight has a fixed role. Use Medium for display and headlines, Regular for sub-headlines, Light for body copy, and Mono Regular for informational text. For the detailed criteria, see Reference Scale.

Use it for tags · dates · reading time · color specs · caption numbers, and not for headlines or body copy.

    Typographic Framework

    Overview

    EO typography is a baseline grid framework measured and scaled from the space type occupies, not from type settings. Set the value of the Line Unit (the base leading, that is, the absolute height between lines), then set each level’s leading as a multiple (x) of it; the type size follows automatically by dividing the leading by the linespacing (leading ÷ type size).

    • Separating the setting of hierarchy from the matching of tonal value gives an easier point of entry when a project’s typography system has to be built from scratch.
    • When switching to another language, the space type occupies stays the same even if the typeface or type size changes, so layout variation is minimal, and adjusting only the tonal value keeps the look and feel consistent.
    • Switching between dark and light mode has the same advantage.
    • In an AI Assisted Design workflow, two levels of decision can be separated: the AI’s efficient layout building and the designer’s eye. Leave the broad hierarchy that follows the content logic to the AI, and refine the visual finish through the separately held values, such as linespacing.

    Read this chapter in the order the framework is carried out. If you need values ready to use, see the presets in Reference Scale. If you are building anew, set the Line Unit following Line Unit and set up the typography through the five steps of Setting Up. For the detailed criteria of each step, see Levelling & Sizing · Linespacing · Letterspacing; for layout, Zoning · Margin · Compound Grid; for other languages and alternative typefaces, Multilingual.

    Typographic Framework

    Line Unit

    The Line Unit is the base unit of the page. Set the leading of every level as a multiple of the Line Unit; the actual type size is the leading divided by the linespacing (%). From here on, the Line Unit is abbreviated as x: values written in x are multiples of the Line Unit, and values written in % are all linespacing ratios. For example, 2.5x means the leading of that level is set at 2.5 times the Line Unit.

    As a rule, base the Line Unit on the content, or the component of it, that is used most widely · most often and carries the most weight on the page.

    • In content layouts, the leading of the body level usually becomes the Line Unit.
    • In visual communication without significant body copy (posters · banners · key visuals), set the Line Unit at 1x or 0.5x the height of the symbol.
    • The recommended Line Unit for web and editorial environments is 28px. Adjust it at the designer’s discretion to suit the page size and the reader’s viewing distance.

    Once the Line Unit is set, subtract the top and bottom margins from the full height of the content area, set a baseline grid in whole multiples of the Line Unit, and reuse it across content in the same series. For details on grid and margin, see Margin and Compound Grid.

    Typographic Framework

    Reference Scale

    A seven-level preset based on Line Unit 1x = 28px. The first letter of a level name is the role of its content: D for display, H for headline, T for text, C for caption. This web guideline is set in four of these levels, H1 · H3 · T1 · C1; refer to the unused ones when creating new levels. Each level specifies multiple (x) · weight · linespacing · letterspacing, and the size in parentheses is the type size rendered on screen at 1x = 28px.

    • D1 — 6x / Medium / 80% / -2.5%. One or two words, such as a tagline or core keyword, on a poster or key visual

    • H1 — 2.5x / Medium / 100% / -1.5% (70px). Main headline · page title

    • D2 — 2.5x / Regular / 100% / -2% (70px). Display at headline level, campaign slogan · sub copy · quotation

    • H2 — 2x / Regular / 115% / -1% (49px). Sub-headline

    • H3 — 1.25x / Regular / 125% / -0.5% Solid Gray · 0 Space Black (28px). Section head · subhead

    • T1 — 1x / Light / 140% / +1% Solid Gray · +1.5% Space Black (20px). Body > brand communication first

    • T2 — 1x / Light / 150% / +1.5% Solid Gray · +2% Space Black (18.67px). Body > readability first

    • C1 — 0.5x / Mono Regular / 111% / -7% (12.6px). Caption · label · tag · spec · date · button

    The recommended weight for each level follows these criteria: Medium for display and headlines (D1 · H1), Regular for sub-display and sub-headlines (D2 · H2 · H3), Light for body copy (T1), Mono Regular for informational text (C1). Use Founders Grotesk Semibold only in a limited way, at the designer’s discretion, for optical correction when Medium-level display text is inverted onto a light background and set small. To emphasize keywords within body copy, do not change the weight; use the Builder Neon color with an underline.

    Set level multiples in steps of 1x · 0.5x · 0.25x, and refine linespacing and letterspacing so that the tonal value carries consistently from each level to its neighbors. For the adjusted values for Korean and Vietnamese, see Multilingual.

    Founders Grotesk has narrow apertures and tight letterspacing, so at body level set it in Light with generous linespacing and slightly opened letterspacing. The presets are designed with a focus on visual communication: we recommend T1 for content where the text read in one go runs to only a few paragraphs, and T2 where the readability of body copy matters most.

    All the presets above assume Air White text on a Solid Gray background. For Space Black text on Air White · Builder Neon backgrounds, see Inversion.

    Typographic Framework

    Setting Up

    How to set up typography in a new medium or format. This is less a fixed sequence than a process of converging on the best result by tuning steps 3-4 against each other.

    1. Decide the number of typography levels. Decide which levels to use based on the amount of information shown on the page. For details, see Levelling & Sizing.
    2. Set the Line Unit and set a baseline grid in the content area of the page. As a rule, size the Line Unit from the content, or the component of it, that carries the most weight or occupies the most space on the page. For details on the Line Unit, see Line Unit; for grid setting, Margin · Compound Grid.
    3. Place the content on the grid and set the hierarchy with each level’s multiple. Set the multiples in steps of 1x · 0.5x · 0.25x. For details, see Levelling & Sizing. Starting from the values in Reference Scale and adjusting them to the medium also works well.
    4. Refine weight · linespacing · letterspacing · color · line breaks for each level to match the tonal value. Tonal value is the brightness of a block of text seen from a distance; it is right when every level looks like the same text enlarged · reduced, at the same brightness. Place the levels side by side and squint, or zoom the screen out, and the differences show. As a rule, the larger the type, the lower the linespacing; the smaller the type, the higher. For details, see Linespacing.
    5. Repeat steps 3-4 until the levels reach a balance in which they look consistently enlarged · reduced according to the hierarchy.

    Typographic Framework

    Levelling & Sizing

    Divide levels by the role of the content. The one or two words that represent the page are display (D), the point where reading starts is headline (H), the text read down the page is text (T), and the information supporting the text is caption (C). Numbers within a role run in order of size.

    • Number of levels — Headline and body, or headline · body · caption. Dividing levels by role is the default, but the difficulty of keeping typography consistent rises steeply with too many levels, so first consider whether information of similar role and priority can be merged into one level.
    • Contrast between levels — The look and feel of typography is largely decided by the degree of contrast between adjacent levels. For roles to be told apart at a glance, the step from body (1x) to headline must be at least double (2-3x), and so must the step from headline to display. Within a role that handles detailed content (H2 → H3), a multiple of about 1.5 is appropriate. Keep all multiples to steps of 1x · 0.5x · 0.25x so that they fit the baseline grid.
    • Symbol and levels — Treat the symbol like a level. Setting 1x or 0.5x of the symbol height as the Line Unit ties the symbol and the typography to the same unit. The size of the symbol follows Symbol › Scalability.

    As a rule, the larger the level, the heavier the weight and the tighter the linespacing and letterspacing. In practice, though, levelling is less a linear procedure in table-of-contents order than a process of tuning Linespacing · Letterspacing · weight against each other at the same time. For the preset values, see Reference Scale.

    Linespacing

    Founders Grotesk Medium

    Linespacing is the height of the space one line of type occupies divided by the type size, expressed in % as in common office software. In the same space, lower linespacing makes the type larger. It corresponds to Line height % in Figma, line-height in CSS and Auto Leading in InDesign. Linespacing can vary with format and type of communication; for the presets by level, see Reference Scale.

    Headlines and display have linespacing of 100% or less, that is, leading equal to or tighter than the type size. Avoid extremely loose or tight linespacing, and where possible also consider revising part of the copy.

    Linespacing

    Founders Grotesk Regular

    The linespacing of sub-headlines (H2 · H3) sits between headline and body (115-125%). They often run to 2-4 lines, so apply wider leading than headlines to raise readability somewhat. D2, the Regular at headline size, follows the same leading rule as headlines.

    Sub-headlines often sit directly above body copy, so also check that their leading does not fall out of step with the body’s baseline grid.

    Linespacing

    Founders Grotesk Light

    Body copy creates its reading rhythm with leading wider than the type size. The longer a line, the more leading it needs, so the eye does not lose the next line. Too wide, though, and the lines drift apart, the paragraph scatters and the visual finish suffers. Within the range that secures readability without strain, tighten the leading little by little until a consistent gray mass forms.

    In content-centered layouts, the leading of the body copy becomes the Line Unit. Changing the body’s Line Unit stretches or shrinks the whole digital layout vertically at the same ratio.

    Linespacing

    Founders Grotesk Mono Regular

    Captions · labels · tags · specs (C1) are short, one or two lines, with small type. Mono has wide letters and a large x-height, so with leading as open as body copy the lines look as if they float; set it at a tighter ratio than body copy.

    The leading of C1 is half the Line Unit. Two lines of caption equal the height of one line of body copy, so informational text also sits on the same baseline grid.

    Letterspacing

    Founders Grotesk Medium

    In large type the spaces between letters look larger too, so tighten the letterspacing. The reference point is where the letters sit together like one block but the strokes stop just short of touching (some horizontally open glyphs may touch each other). Too tight, and combinations of consecutive vertical strokes read as one mass; too loose, and words scatter into letters and the headline loses its weight.

    Letterspacing

    Founders Grotesk Regular

    Because the inherent tonal value of Regular is lower than that of Medium, securing a tonal value at sub-headline level close to that of the headline level calls for relatively tighter letterspacing. For example, H1 uses Medium at -1.5% letterspacing, while D2, at the same type size, applies an even tighter -2%.

    Letterspacing

    Founders Grotesk Light

    In small type the spaces look relatively small, so open the letterspacing to around 1-1.5%, taking light text on a dark background as the reference. Because the thin weight loses readability quickly when the letterspacing is tightened, find the compromise according to which matters more, uniform tonal value or readability.

    Letterspacing

    Founders Grotesk Mono Regular

    By nature, Mono is highly distinguishable even at small sizes, but its readability as running text is low, so tighten the letterspacing to around -7%. If many long words make the lines run long, consider switching to the body typeface.

    Alignment

    Content in EO brand communication is left aligned by default. Center alignment is allowed only when the text is a single line, as with standalone symbol icons and merch back prints; do not use justified text. When body copy runs in several columns, align the first-line baselines of all columns. Align the symbol left to the image’s left edge and the caption right to its right edge. A single left alignment line becomes the reference line of the page: headline · sub-headline · body start from the same line, and the reader starts reading at the same place on every line. Right alignment loses that reference because the start of each line moves, and justified text opens the word spaces and makes the tonal value uneven. This rule applies to every weight.

    The exception is informational text (C1 · Mono). A caption beneath an image may be right aligned to the right edge, paired with the symbol left aligned to the left edge, and a caption attached to a simple graphic such as an icon · shape · illustration may be center aligned above or below it. All other Mono text is left aligned like the other levels, and justified text is not used for Mono either.

    Ragging

    A paragraph has a bad rag when its edge feels irregular, when a particular line sticks out, or when a single word is left alone on the last line.

    Headlines are short with few lines, so the rag shows plainly. Break lines so that each line holds a unit of meaning, as in “Build / Anyway.”, and avoid the staircase shape of alternating long and short lines. In body copy, move words to the next line until the edge is even and the copy reads well.

    Grid Setting

    Zoning

    Divide the page into a graphic pattern area and a content area. Ideally the graphic pattern area is close to a square on 3:4 · A-series · business card formats, takes around 70% of the page on horizontal wide formats, and around half on vertical roll-ups. Communication pages with little information may also be divided into four, with content alternating with the pattern or gathered to one side. Typography in the content area runs left and top aligned, so when splitting the page side by side, prefer placing the graphic pattern area on the right; when splitting it top and bottom, at the top.

    Place the graphic pattern area full bleed, ignoring the margin, and arrange its units following Graphic Pattern › Zoning. For the boundary between the two areas, set the Compound Grid first, check the right proportion of the areas against its columns · rows, and align the boundary to the nearest line. If it does not fall exactly on a line, adjust it to the midline of a column · row or to a baseline.

    The content area is what remains, and the margin is set from this area. In a four-way division, use one of the divided content areas as the reference. For pages whose front and back are linked, such as business cards, use the side that carries the main content.

    Grid Setting

    Margin

    Set the margin of the content area equal on all four sides, based on 1/24 of the area’s long side; we recommend setting the horizontal margins about 10% narrower. The final value settles between 1/22 and 1/25 as the number of baseline cells is matched in Compound Grid. On pages read up close the margin is about the same scale as the Line Unit; on pages seen from a distance it can shrink to around 70-80% of the Line Unit.

    On a side where typography meets the graphic pattern, leave about 1.5 times the margin. The top edge of typography is a gray edge, because the tops of the letters are uneven, so compensate with more space than at crisp edges such as the left alignment line · the baseline · the left and bottom of the symbol. Text is left aligned, so its right side does not meet the pattern.

    Grid Setting

    Compound Grid

    The base grid is a baseline grid in whole multiples of the Line Unit. The margin is set first in Margin from the content area, and settles between 1/22 and 1/25 as the number of baseline cells N is matched. Then verify that the margin falls within 0.8-1.1 times the Line Unit on pages read up close, and 0.7-0.8 times on pages seen from a distance.

    For large pages or layouts with complex components, we recommend the Compound Grid, which combines a modular grid with this baseline grid. It is a modular grid that divides the content area evenly with gutters of one Line Unit, and since the height of a module cell is also a whole multiple of the Line Unit, it is fully compatible with the baseline grid.

    • Compound Grid rows — The Compound Grid can be applied when the total number of baseline cells satisfies N = number of rows R × (Line Units per row n + 1) − 1. For example, 35 cells divide into 6 rows × 5 cells or 4 rows × 8 cells. 47 cells allow 4 · 6 · 8 · 12 rows alike, making it the most flexible. With the gutter between rows widened to 2 cells, 47 cells also divide into 7 rows × 5 cells.
    • Compound Grid columns — 12 columns × 6 rows are commonly used on 16:9 pages and 6 columns × 6 rows on A-series formats, but set the number freely at the designer’s discretion. On A-series or similarly proportioned pages, set it from the page proportion so that the graphic pattern area comes close to a square. The gutter between columns is 1x the Line Unit.

    Typography

    Inversion

    EO typography is built primarily for light text, such as Air White · Medium Gray, on dark backgrounds such as Solid Gray · Space Black. As with the signature’s descriptor, when you want dark text on a light background and simply invert the colors, an optical illusion occurs: at the same weight and letterspacing, the letters look thinner and the letterspacing looks wider.

    In that case, keep the Line Unit · level multiples · weights as they are, correct the type size to 1.05 times (linespacing 0.95 times) and apply 1% tighter letterspacing. The tonal value then stays at a consistent level on light backgrounds too, and because the space the type occupies is unchanged, layout changes are kept to a minimum.

    Multilingual

    Use Pretendard for Korean and Noto Sans for Vietnamese. When an existing layout is changed to a multilingual typeface, the Line Unit and level multiples stay the same, so the layout does not move when the language changes. Below are multilingual conversions for T1 · H3 of the Reference Scale.

    • Korean Pretendard — T1 is Regular · 165% · -1.5% · baseline +0.2x, and H3 is Medium · 165% · -2.5% · baseline -0.05x. The rendered type size is about 0.85 times that of Founders Grotesk at the same level.
    • Vietnamese Noto Sans — T1 is DemiLight · 175% · -1% · baseline +0.05x, and H3 is Regular · 175% · -3% · baseline +0.05x. The rendered type size is about 0.8 times that of Founders Grotesk at the same level.

    The baseline correction is for matching positions relative to the text box in editorial design tools. In digital environments the browser aligns baselines by itself, so on the web the correction is rarely needed, but where type is shown large, as with display fonts, correct it with a separate margin inside the text box.

    These two typefaces are also the alternatives in environments where Founders Grotesk cannot be used (email, system-font restrictions on external platforms and document tools, and so on). In that case, set English in Pretendard first as well, and use Noto Sans where Pretendard cannot be used or does not support the language.
